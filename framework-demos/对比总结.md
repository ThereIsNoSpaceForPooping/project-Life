# Python 后端框架对比总结

> 基于 FastAPI、Sanic、Flask 三个框架的实际代码对比

---

## 一、应用创建与启动

### FastAPI

```python
# main.py
import uvicorn
from app import create_app

app = create_app()

if __name__ == "__main__":
    uvicorn.run("main:app", host="0.0.0.0", port=8001, reload=True)
```

- 依赖 **Uvicorn**（ASGI 服务器）启动
- 支持 `reload=True` 热重载
- 原生异步（ASGI）

### Sanic

```python
# main.py
from app import create_app

app = create_app()

if __name__ == "__main__":
    app.run(host="0.0.0.0", port=8002, debug=True, auto_reload=True)
```

- **内置服务器**，无需额外依赖
- `app.run()` 直接启动
- 原生异步（ASGI）

### Flask

```python
# main.py
from app import create_app

app = create_app()

if __name__ == "__main__":
    app.run(host="0.0.0.0", port=8003, debug=True)
```

- **内置服务器**，无需额外依赖
- `app.run()` 直接启动
- 同步模型（WSGI）

## 二、路由注册机制

### FastAPI — APIRouter

```python
# app/api/routes/user.py
from fastapi import APIRouter

router = APIRouter()              # 定义路由对象

@router.get("/")
async def get_users():
    pass

# app/api/routes/__init__.py
from app.api.routes.user import router as user_router    # 重命名导出
from app.api.routes.health import router as health_router # 避免命名冲突

# app/api/__init__.py
from app.api.routes import user_router, health_router

api_router = APIRouter()
api_router.include_router(user_router, prefix="/api/users", tags=["用户管理"])
```

**特点**：
- 使用 `APIRouter` 组织路由
- `tags` 参数用于 Swagger 文档分组
- `prefix` 在注册时统一添加
- 多个文件都叫 `router`，通过 `as` 重命名避免冲突

### Sanic — Blueprint

```python
# app/api/routes/user.py
from sanic import Blueprint

bp = Blueprint("users", url_prefix="/api/users")  # 定义时直接设置前缀

@bp.get("/")
async def get_users(request):
    pass

# app/api/__init__.py
from app.api.routes.user import bp as user_bp

def register_routes(app):
    app.blueprint(user_bp)
```

**特点**：
- 使用 `Blueprint` 组织路由
- `url_prefix` 在定义时设置（不是注册时）
- 每个处理函数**必须**接收 `request` 参数
- 通过 `app.blueprint()` 注册

### Flask — Blueprint

```python
# app/api/routes/user.py
from flask import Blueprint

user_bp = Blueprint("users", __name__, url_prefix="/api/users")

@user_bp.route("/", methods=["GET"])
def get_users():
    pass

# app/api/__init__.py
from app.api.routes.user import user_bp

def register_blueprints(app):
    app.register_blueprint(user_bp)
```

**特点**：
- 使用 `Blueprint` 组织路由
- 需要传 `__name__` 参数（Flask 用于定位模板等静态资源）
- `methods` 参数显式声明 HTTP 方法
- 通过 `app.register_blueprint()` 注册

## 三、路由装饰器对比

| 操作 | FastAPI | Sanic | Flask |
|------|---------|-------|-------|
| GET | `@router.get("/")` | `@bp.get("/")` | `@bp.route("/", methods=["GET"])` |
| POST | `@router.post("/")` | `@bp.post("/")` | `@bp.route("/", methods=["POST"])` |
| PUT | `@router.put("/{id}")` | `@bp.put("/<id:int>")` | `@bp.route("/<int:id>", methods=["PUT"])` |
| DELETE | `@router.delete("/{id}")` | `@bp.delete("/<id:int>")` | `@bp.route("/<int:id>", methods=["DELETE"])` |

### 路径参数语法差异

```python
# FastAPI — 花括号 + 类型提示
@router.get("/{user_id}")
async def get_user(user_id: int):     # 自动类型转换
    pass

# Sanic — 尖括号 + :类型
@bp.get("/<user_id:int>")
async def get_user(request, user_id: int):
    pass

# Flask — 尖括号 + type:名称
@bp.route("/<int:user_id>")
def get_user(user_id: int):
    pass
```

## 四、请求参数获取

### 查询参数（Query String）

```python
# FastAPI — 自动解析，带类型验证
@router.get("/")
async def get_users(
    skip: int = Query(0, ge=0, description="跳过条数"),
    limit: int = Query(10, ge=1, le=100, description="每页条数")
):
    pass

# Sanic — 手动从 request.args 获取
@bp.get("/")
async def get_users(request):
    skip = int(request.args.get("skip", 0))
    limit = int(request.args.get("limit", 10))

# Flask — 手动从 request.args 获取
@bp.route("/")
def get_users():
    skip = request.args.get("skip", 0, type=int)
    limit = request.args.get("limit", 10, type=int)
```

### 请求体（JSON Body）

```python
# FastAPI — 自动解析 + 验证，直接作为函数参数
@router.post("/")
async def create_user(user_data: UserCreate):  # Pydantic 模型自动解析
    pass

# Sanic — 手动解析 request.json，用 ** 解包
@bp.post("/")
async def create_user(request):
    user_data = UserCreate(**request.json)     # ** 将字典解包为关键字参数

# Flask — 手动解析 request.get_json()，用 ** 解包
@bp.route("/", methods=["POST"])
def create_user():
    data = request.get_json()
    user_data = UserCreate(**data)             # ** 将字典解包为关键字参数
```

**`**` 解包语法说明**：

```python
# request.json 返回字典
{"name": "张三", "email": "zhang@example.com", "age": 25}

# ** 解包后等价于
UserCreate(name="张三", email="zhang@example.com", age=25)

# 不用 ** 会报错（字典作为位置参数传入，而非关键字参数）
UserCreate({"name": "张三", ...})  # ❌ 报错
```

## 五、响应返回

```python
# FastAPI — 直接返回字典/模型，自动序列化
@router.get("/")
async def get_users():
    return users                    # 自动 JSON 序列化
    # 或
    return {"message": "ok"}        # 字典自动序列化

# Sanic — 必须使用 json() 包装
@bp.get("/")
async def get_users(request):
    return json(users)              # 必须用 json()
    # 或
    return json({"message": "ok"})

# Flask — 必须使用 jsonify() 包装
@bp.route("/")
def get_users():
    return jsonify(users)           # 必须用 jsonify()
    # 或
    return jsonify({"message": "ok"})
```

### 错误响应

```python
# FastAPI — 抛出异常，自动处理
from fastapi import HTTPException

raise HTTPException(status_code=404, detail="用户不存在")

# Sanic — 抛出内置异常
from sanic.exceptions import NotFound

raise NotFound("用户不存在")

# Flask — 手动返回错误响应 + 状态码
return jsonify({"error": "用户不存在"}), 404
```

## 六、异步支持

```python
# FastAPI — 原生异步
@router.get("/async-demo")
async def async_demo():
    await asyncio.sleep(1)          # 非阻塞等待
    return {"message": "完成"}

# Sanic — 原生异步
@bp.get("/async-demo")
async def async_demo(request):
    await asyncio.sleep(1)          # 非阻塞等待
    return json({"message": "完成"})

# Flask — 不支持异步（同步阻塞）
@bp.route("/sync-demo")
def sync_demo():
    time.sleep(1)                   # 阻塞等待
    return jsonify({"message": "完成"})
```

## 七、中间件

### FastAPI

```python
# 方式一：使用 @app.middleware 装饰器
@app.middleware("http")
async def log_middleware(request: Request, call_next):
    response = await call_next(request)
    return response

# 方式二：添加 CORS 中间件（Starlette 中间件）
app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_methods=["*"],
)
```

### Sanic

```python
# 使用 @app.middleware 装饰器
@app.middleware("request")
async def log_request(request):
    print(f"[{request.method}] {request.path}")

@app.middleware("response")
async def add_header(request, response):
    response.headers["X-Framework"] = "Sanic"
```

### Flask

```python
# 使用 @app.before_request / @app.after_request
@app.before_request
def log_request():
    print(f"[{request.method}] {request.path}")

@app.after_request
def add_header(response):
    response.headers["X-Framework"] = "Flask"
    return response
```

## 八、WebSocket 支持

```python
# FastAPI — 需要额外配置
from fastapi import WebSocket

@app.websocket("/ws")
async def websocket_endpoint(websocket: WebSocket):
    await websocket.accept()
    data = await websocket.receive_text()
    await websocket.send_text(f"Echo: {data}")
    await websocket.close()

# Sanic — 原生支持，语法简洁
@bp.websocket("/ws")
async def websocket_handler(request, ws):
    while True:
        data = await ws.recv()
        await ws.send(f"Echo: {data}")

# Flask — 不支持（需要 Flask-SocketIO 扩展）
```

## 十、依赖注入

```python
# FastAPI — 内置 Depends 系统（独有特性）
from fastapi import Depends

async def get_current_user(token: str = Header(...)):
    """验证 Token，返回当前用户"""
    user = verify_token(token)
    return user

@router.get("/profile")
async def get_profile(user: User = Depends(get_current_user)):
    # user 自动注入，无需手动验证
    return user

# Sanic — 不支持
# Flask — 不支持
```

## 十一、综合对比表

| 特性 | FastAPI | Sanic | Flask |
|------|---------|-------|-------|
| **协议** | ASGI | ASGI | WSGI |
| **异步** | ✅ 原生 | ✅ 原生 | ❌ 同步 |
| **路由对象** | APIRouter | Blueprint | Blueprint |
| **路由装饰器** | `@router.get()` | `@bp.get()` | `@bp.route(methods=[...])` |
| **路径参数** | `{id}` | `<id:int>` | `<int:id>` |
| **查询参数** | 自动解析 | 手动获取 | 手动获取 |
| **请求体** | 自动解析验证 | 手动解析 | 手动解析 |
| **响应方式** | 直接返回 | `json()` | `jsonify()` |
| **错误处理** | `HTTPException` | `NotFound` | 手动返回状态码 |
| **自动文档** | ✅ Swagger/ReDoc | ❌ | ❌ |
| **依赖注入** | ✅ `Depends()` | ❌ | ❌ |
| **WebSocket** | ✅ 支持 | ✅ 原生 | ❌ 不支持 |
| **模板渲染** | ❌ 需扩展 | ❌ 需扩展 | ✅ Jinja2 内置 |
| **Session** | ❌ 需扩展 | ❌ 需扩展 | ✅ 内置 |
| **中间件** | Starlette 中间件 | 请求/响应中间件 | before/after 钩子 |
| **性能** | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ | ⭐⭐⭐ |
| **学习曲线** | 低 | 低 | 低 |
| **生态成熟度** | ⭐⭐⭐ | ⭐⭐⭐ | ⭐⭐⭐⭐⭐ |

## 十二、选型建议

| 场景 | 推荐框架 | 理由 |
|------|----------|------|
| RESTful API 服务 | **FastAPI** | 自动文档、类型验证、依赖注入 |
| AI/ML 模型服务 | **FastAPI** | 异步支持、性能优秀、Pydantic 集成 |
| 高并发实时通信 | **Sanic** | 原生 WebSocket、流式响应 |
| 传统 Web 应用 | **Flask** | 模板渲染、Session、生态丰富 |
| 快速原型开发 | **Flask** | 最简单、扩展灵活 |
| 微服务架构 | **FastAPI** | 轻量、高性能、类型安全 |
