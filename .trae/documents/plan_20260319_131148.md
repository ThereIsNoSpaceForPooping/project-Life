# 智能体架构实现计划（企业级增强版）

## 目标

为每种 Agent 架构创建完整的智能体，实现 100% 功能闭环：

* ✅ 结合记忆系统（Multi-Layer Memory）

* ✅ 结合 RAG（检索增强生成）

* ✅ 上下文工程（动态压缩、分块）

* ✅ 配以前端页面展示处理流程

## 技术栈

| 技术                      | 用途         |
| ----------------------- | ---------- |
| **LangChain**           | Agent 框架核心 |
| **LangGraph**           | 工作流编排      |
| **LangChain-Community** | LLM 调用（千问） |
| **FAISS**               | 向量数据库（RAG） |
| **JSON**                | 记忆持久化      |
| **FastAPI**             | API 服务     |
| **HTML/CSS/JS**         | 前端展示       |

## 架构清单（共6种）

| # | 架构                | 文件                      | 核心特性               |
| - | ----------------- | ----------------------- | ------------------ |
| 1 | Simple Agent      | `simple_agent.py`       | 直接 LLM + 记忆        |
| 2 | Tool Agent        | `tool_agent.py`         | ReAct + 工具 + RAG   |
| 3 | Plan-and-Execute  | `plan_execute_agent.py` | 规划 + 执行 + 记忆       |
| 4 | Agent Swarm       | `swarm_agent.py`        | 多 Agent + RAG + 记忆 |
| 5 | Human-in-the-Loop | `human_loop_agent.py`   | 人工审核 + 上下文         |
| 6 | Reflexion Agent   | `reflexion_agent.py`    | 反思 + RAG + 记忆      |

## 详细设计

### 共同特性（每个 Agent 都有）

1. **记忆系统**

   * Working Memory: 最近 N 条消息

   * Episodic Memory: 历史摘要

   * Semantic Memory: 重要信息提取

2. **RAG 系统**

   * 向量存储：FAISS

   * 文档加载器：文本文件

   * 相似度检索

3. **上下文工程**

   * 动态压缩（token 阈值触发）

   * 上下文窗口管理

   * 关键信息提取

### 各架构实现

#### 1. Simple Agent

```
输入 → 加载记忆 → RAG检索 → LLM → 保存记忆 → 输出
```

#### 2. Tool Agent (ReAct)

```
输入 → 记忆+RAG → 思考 → 行动 → 观察 → ... → 输出
```

#### 3. Plan-and-Execute

```
输入 → 规划(LLM) → 步骤1(RAG+工具) → 步骤2 → ... → 输出
```

#### 4. Agent Swarm

```
输入 → Agent1(RAG) → Agent2(分析) → Agent3(写作) → 输出
```

#### 5. Human-in-the-Loop

```
执行中 → 暂停 → [人类审核] → 继续/修改 → 输出
```

#### 6. Reflexion Agent

```
执行 → 反思(LLM评估) → 成功? → 是→输出 / 否→重试
```

## API 设计

```python
# 统一入口
POST /api/agent/{agent_type}/run
{
  "input": "用户问题",
  "rag_enabled": true,      # 是否启用 RAG
  "memory_enabled": true,    # 是否启用记忆
  "human_review": false,     # 是否需要人工审核
  "max_steps": 10           # 最大步数
}

# 响应（展示完整流程）
{
  "agent_type": "tool_agent",
  "steps": [
    {"step": 1, "type": "memory", "content": "加载记忆..."},
    {"step": 2, "type": "rag", "content": "检索到3个相关文档"},
    {"step": 3, "type": "thought", "content": "思考中..."},
    {"step": 4, "type": "action", "tool": "search", "input": "..."},
    {"step": 5, "type": "observation", "content": "结果..."},
    {"step": 6, "type": "final", "content": "最终答案"}
  ],
  "memory_saved": true,
  "rag_retrieved": 3,
  "result": "..."
}
```
